# Освітній Простір №8 — Курс цифрової грамотності

Інтерактивний офлайн-курс цифрової грамотності пілотного проєкту **«Освітній простір»**
(ДУ «Житомирська установа виконання покарань №8»). Від архітектури цифрових пристроїв —
до штучного інтелекту, цифрових державних послуг і працевлаштування.

> Навчання як шлях · рівний — рівному

## Що це

- **13 модулів** (M0–M12): вступ → ментальна карта (архітектура й історія) → база →
  Дія та е-послуги → продуктивність і робота → штучний інтелект → оркестрація AI → підсумок.
- **Особисті кабінети учнів** — на спільних ПК кілька профілів, вхід за іменем + PIN,
  окремий прогрес, експорт/імпорт профілю файлом.
- **Кабінет викладача** — огляд групи, імпорт профілів, видача сертифікатів.
- **Персональний сертифікат + «Карта індивідуального плану та успішності»** наприкінці.
- **Повністю офлайн.** Жодних зовнішніх запитів — працює навіть подвійним кліком по `index.html`.

## Як запустити

- **Найпростіше:** відкрити `index.html` подвійним кліком (працює на `file://`).
- **Або** через локальний сервер: `python -m http.server` у цій папці → `http://localhost:8000`.

Для учня: «Я тут уперше» → ввести ім'я, групу, PIN → курс відкриється.
Для викладача: посилання «Кабінет викладача» внизу екрана входу.

## Структура

```
index.html                 головна (вхід + курс)
kabinet-vykladacha.html    кабінет викладача
certificate/sertyfikat.html сертифікат + карта профілю (друк → PDF)
content/course.js          ← ЗМІСТ КУРСУ (правити тут): модулі, уроки, тести
js/  cabinet · progress · quiz · app · certificate · instructor
css/style.css              бренд-тема (світла/темна), шрифт e-Ukraine
brand/                     логотип, палітра, гайд (brand-guide.md)
assets/schemes/            векторні схеми (ментальна карта, фон Нейман, шкали)
instructor/                методичка (планується)
PLAN.md · PROGRESS.md      план і журнал
```

## Шрифт

Курс використовує офіційний шрифт **e-Ukraine** (Дія). Поклади файли
`e-Ukraine-Regular.woff2`, `e-Ukraine-Medium.woff2`, `e-Ukraine-Bold.woff2` у `brand/fonts/`.
Без них працює системний резерв (Inter / Segoe UI).

## Статус

Готово: бренд, рушій курсу, кабінети, сертифікат, модулі **M0** і **M1** з повним змістом.
Далі: зміст модулів **M2–M12**, методичка для викладача, (опційно) растрові обкладинки.
