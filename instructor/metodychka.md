# Методичка викладача
## Курс «Цифрова грамотність» — «Освітній простір», ДУ «Житомирська УВП №8»

**Аудиторія:** засуджені до довічного позбавлення волі, які вже пройшли базовий курс КГ 2022.  
**Обладнання:** 5 ПК + 3 ноутбуки, проєктор, Wi-Fi з обмеженим доступом.  
**Рекомендована тривалість:** 45–60 хвилин на модуль, 1–2 рази на тиждень.

---

## Структура курсу (13 модулів)

| Блок | Модулі | Тема |
|------|--------|------|
| 0 — Вступ | M0 | Проєкт «Освітній простір» |
| I — Ментальна карта | M1 | Архітектура та історія цифрових пристроїв |
| II — База 2022 | M2–M3 | ОС і файли; Інтернет і безпека (повторення) |
| III — Е-держава | M4 | Дія та електронні послуги |
| IV — Продуктивність | M5–M6 | Документи; Резюме та Біржа праці |
| V — ШІ: грамотність | M7–M9 | Що таке AI; Промптинг; Критичне мислення |
| VI — Горизонт | M10–M11 | Оркестрація AI-інструментів (IT-трек) |
| VII — Підсумок | M12 | Цифровий план і сертифікат |

---

## Формат одного заняття

1. **Пояснення (10–15 хв)** — викладач показує зміст модуля на проєкторі; учні можуть одразу читати на своєму екрані.
2. **Самостійна робота (20–25 хв)** — кожен читає урок у своєму особистому кабінеті, розглядає схеми (клік на ілюстрацію — збільшення на весь екран).
3. **Тест (5–7 хв)** — вбудований тест у кінці модуля; результат зберігається автоматично.
4. **Рефлексія (3–5 хв)** — усне підбиття підсумків; 3 питання рефлексії у курсі — як орієнтир для розмови.
5. **Тренажер набору (10–15 хв, за наявності часу)** — розділ «⌨ Тренажер набору» в меню: 6 уроків від домашнього ряду до тексту.

## Кабінети учнів — налаштування

**Перший запуск:**
- Відкрити `OsvitniyProstir8-1.0.0.exe` з флешки.
- Натиснути «➕ Новий учень» → ввести ім'я, прізвище, групу, PIN (4 цифри).
- Кожен учень входить під своїм PIN — прогрес зберігається окремо.

**PIN забутий / потрібно скинути:**
- Відкрити «Кабінет викладача» → знайти учня → «Змінити PIN».
- Пароль кабінету викладача: стандартний (налаштовується при першому вході).

**Що зберігається у кабінеті:**
- Пройдені модулі та результати тестів.
- Рекорди тренажера набору (знаків/хв, точність).
- Рівень сертифіката (Базовий / Продвинутий / IT-Профі).

**Збереження результатів на флешку (Windows .exe):**
- Кнопка «📤 Здати роботу викладачу» → нативний діалог збереження → вибрати флешку.
- Викладач імпортує файл у «Кабінет викладача» → бачить прогрес учня.

## AI-практика під наглядом (M7–M9)

Модулі M7–M9 пояснюють AI концептуально. Якщо є керований доступ до мережі:

**Дозволено під наглядом:**
- Демонстрація Claude / ChatGPT викладачем на проєкторі.
- Складання промпту разом (формула Завдання + Контекст + Формат).
- Перевірка відповіді AI через .gov.ua (M9 — критичне мислення).

**Не рекомендується:**
- Самостійний доступ учнів до AI без нагляду.
- Введення персональних даних в AI-сервіси.
- Запити на юридичні поради (нагадати: AI не замінює юриста).

**Якщо мережі немає:**
- Показати заздалегідь підготовлені скриншоти діалогів.
- Провести рольову гру: один учень формулює промпт, інший «відповідає як AI» (допомагає зрозуміти структуру).

## Кабінет викладача

Відкривається через `kabinet-vykladacha.html` або кнопку «👨‍🏫 Кабінет викладача» у меню.

**Що можна:**
- Переглядати список учнів і їхній прогрес по модулях.
- Скидати PIN учня.
- Імпортувати файл результатів з флешки.
- Додавати / видаляти учнів.

## Сертифікат

Генерується автоматично після проходження курсу. Три рівні:

| Рівень | Умова |
|--------|-------|
| **Базовий** | Пройдено M0–M6, M12; тести ≥ 60% |
| **Продвинутий** | + M7–M9; тести ≥ 75% |
| **IT-Профі** | + M10–M11; тести ≥ 85% |

Сертифікат містить ім'я учня, дату, рівень і підпис викладача. Друкується через кнопку «🖨 Друк» → PDF → лазерний принтер.

## Технічні нотатки

- **Запуск з флешки (.exe):** SmartScreen покаже попередження → «Докладніше» → «Виконати все одно».
- **Android-планшет (.apk):** потрібен дозвіл «Встановлення з невідомих джерел» у налаштуваннях.
- **Дані учнів:** зберігаються лише локально на ПК установи. В інтернет нічого не передається.
- **Розмір тексту:** кнопки А− / А+ у шапці; режим «Проєктор» (кнопка 📽) — максимальний шрифт для показу на екрані.
- **Темна тема:** кнопка 🌓 у шапці — зручна при проєкції у затемненій залі.
- **Онлайн-версія** (якщо є інтернет): https://gregory-ivd.github.io/osvitniy-prostir/
